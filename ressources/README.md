# Ressources du GéoStandard PPR

Ce répertoire contient les ressources utiles à la constitution, la compréhension ou l'utilisation du standard.

- Le répertoire [jeux-test](./jeux-test/) contient des PPRs conformes au nouveau standard ;
- Le répertoire [gabarits](./gabarits/) contient une liste de gabarits au format GeoPackage respectant la structure du standard ;
- La page [FAQ](./FAQ.md) rassemble quelques conseils relatifs à la mise en oeuvre du standard PPR.
